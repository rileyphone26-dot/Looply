## TikTok integration

The OAuth and Display API scaffold is prepared but is not active until the Supabase SQL migration is run, the `tiktok-auth` Edge Function is deployed, and TikTok developer credentials are configured securely.

See [docs/TIKTOK_SETUP.md](docs/TIKTOK_SETUP.md) for the setup steps. Never commit TikTok client secrets or access tokens to this repository.
